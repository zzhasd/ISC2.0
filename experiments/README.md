# 历史实验与运行脚本

当前三个主实验的代码入口为根目录`isc112/`：

```powershell
python -m isc112 all
```

主输入为`data/isc112/`，主报告、统计和论文图为`results/isc112/`，统一分析112段完整自然对话。

本目录平铺脚本保留原路径，以便原协议、请求哈希、导入链和历史运行记录可追溯。它们不是当前论文主图入口。不要为了重画图重新运行任何`*_run.py`或API脚本。

| 历史脚本 | 用途 |
| --- | --- |
| `isc4_*` | 早期完整A及逐前缀运行、参考、审核与统计 |
| `isc7_*` | 原2×2推理模块、调用及审核 |
| `extension80*` | 采样扩充过程的冻结产物生成与审计 |
| `recovery112*` | 已授权缺失补跑、首个有效返回选择、重试审计 |
| `plot_main_experiments.py`、`paper_figures112.py` | 已归档的阶段性绘图方式 |
| 其他脚本 | 辅助方法、早期受控/自然先导实验及其复现 |

当前包复用已经冻结的数据与审核决定，并通过逐前缀、逐对话结果回归检查；不依赖这些历史脚本执行新的推理调用。旧项目说明保存在`docs/history/README_before_isc112.md`。
