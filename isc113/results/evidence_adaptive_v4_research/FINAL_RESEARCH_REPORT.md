# 本轮研究与追加实验总报告

已完成原始文献检索、v3 逐条错误分析、v4 298 段追加、v5 298 段选择性审查，以及 v3/v4 298 段同批联合评审。结果未得到稳定的“所有指标全面胜出”版本，建议维持 v3 作为原默认候选，不用 v4/v5 覆盖原算法或历史评价。

## 历史主表口径

评价仍 prompts-v2.py、原 validate_matches / score_item / four_metrics；588 条真实参考，262 条 E1/E2 参考。

|---|---:|---:|---:|---:|---:|

原输出与计数：v3 正确输出 141/701、恢复 111/588、有据恢复 108/262；v4 为 126/826、125/588、119/262；v5 为 119/645、118/588、114/262。v5 未生成任何新事实，其结果为 v4 文本不变的子集，复用已核验绑定的逐条评审，避免删选后重抽标签。

## 找到的瓶颈

1. 隐式推断的准确性远低于直接描述。v4 explicit 分支 92/351=26.21%，presupposition 为 23/238=9.66%；coreference、causal、cross_turn 更低。语义上看似连贯不等于由 A 文本蕴含。
2. v3 有 123 条 broader、56 条 narrower，占 701 条输出的 25.53%。将事件拆碎、遗漏关键对象/时间、补充过度具体的场景都损害严格 equivalent 命中；但照参考补隐藏细节会泄漏，不能采用。
3. v3 的 141 个正确输出仅恢复 111 个不同参考，增加重复表述不等于恢复新属性。原 Precision 仍按输出计数，两个 Recall 保留最大一对一匹配，未改评价公式。
4. 评价器有可观波动：v1/v3 的 444 条相同文本中 52 条关系变动，15 条严格命中翻转。先前很小的精度领先不应解释为稳健算法提升。
5. 参考中只有 262/588 是强可见证据级别。继续猜测隐藏回复可能偶然提升全参考 Recall，却损害可信度；严格证据目标与隐藏信息召回存在约束。

## 论文支持了什么

[Extracting and Inferring Personal Attributes from Dialogue (2022)](https://aclanthology.org/2022.nlp4convai-1.6/) 使用约束生成和判别重排；本项目借鉴两阶段约束，没有复现其训练方法。

[Decontextualization (2021)](https://aclanthology.org/2021.tacl-1.27/) 强调独立表述应保持语境中的原意；据此加入完整角色、事件限定与意义保持。

[CoVe (2023)](https://arxiv.org/abs/2309.11495) 研究独立验证；据此隐藏初稿置信度与自评级，并把新增审查限制为 keep/reject。本实现不是完整四阶段 CoVe，也不具备外部真值反馈。

[Intrinsic self-correction limitation (ICLR 2024)](https://arxiv.org/abs/2310.01798) 在推理任务中发现缺乏可靠反馈的自我纠错可能失效，提醒不能仅靠更多同模型复核保证改善。

[Evaluator consistency (COLING 2025)](https://aclanthology.org/2025.coling-main.710/) 与 [Permutation-consensus factuality judging (2026)](https://arxiv.org/abs/2603.20562) 支持单独检查评审一致性。没有将多次共识换入原标准；仅新增同批共享判断的对照。

详细检索、预设目标与适用边界见 RESEARCH.md、JUDGE_STABILITY_RESEARCH.md。

## 同批共享判断对照

相同预测文本在同一对话中只得到一个语义判断，继续同一 prompt 和评分函数，独立保存，不覆盖历史表。

这份对照未支持 v4/v5 全面优于 v3。事后只保留 explicit+presupposition 的语言证据消融在历史口径为 21.6891% / 19.2177% / 41.9847%，看似全升；但在同批口径变为 20.7294% / 18.3673% / 39.3130%，召回优势消失。因此没有将其包装成“成功 v6”，也没有据有利表格替换主表。

并行 EFCR 研究的独立活跃文件按明确审计排除，没有修改其内容。所有失败请求、网络恢复、中间算法和消融完整保留。没有使用参考、完整 B、逐样本规则或测试指标搜索的置信度阈值参与推断。
