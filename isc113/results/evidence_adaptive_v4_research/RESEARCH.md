# v4 文献调查、瓶颈诊断与预设实验

研究范围：既有 v1/v2/v3 的 A→B 预测、原始调用、匹配记录，以及公开原始论文。未修改原算法、588 条参考或 prompts-v2.py。诊断用同一 298 段，后续属于适应性追加实验，不是独立泛化检验。

v3：701 条输出，equivalent=141、broader=123、narrower=56、none=381。none 表示当前固定参考未命中，不等于开放世界中事实必然为假。问题包括无用的会话元属性、主体错配、同一事实的多种表述、时间/事件限定脱落与过度具体化。v3 的 141 个正确输出仅恢复 111 个不同参考，说明添加输出不等同于恢复新属性。

v3 三阶段已知 token 1,199,268（下界 4024.389262/段）：v1=283,852、v2 coverage=404,648、v2 review=510,768。v3 的保守 E1 融合仍承担全部生成/复核成本；新一轮应同时减少低效复核和无效输出。

| 原始研究 | 支持的思路 | 本项目采用与边界 |
|---|---|---|
| [Extracting and Inferring Personal Attributes from Dialogue, 2022](https://aclanthology.org/2022.nlp4convai-1.6/) | 约束属性生成与判别重排结合，用于显式及非逐字属性 | 两阶段覆盖候选与判别式归因复核；没有复现论文训练出的 reranker，不移用其性能数字 |
| [Decontextualization: Making Sentences Stand-Alone, 2021](https://aclanthology.org/2021.tacl-1.27/) | 独立表述应保持原语境中的真值条件 | 保留主体、对象、时间、模态和定义性限定；不把同一事件拆成过宽碎片，也不补隐藏细节 |
| [Chain-of-Verification, 2023](https://arxiv.org/abs/2309.11495) | 独立验证减少对初稿答案的偏信 | 隐去候选置信度与 E1/E2 自评级，要求重新从 A 原文判断；本实现不是论文完整四阶段 CoVe，也不是外部真值验证 |
| [Large Language Models Cannot Self-Correct Reasoning Yet, ICLR 2024](https://arxiv.org/abs/2310.01798) | 推理任务中缺乏可靠反馈的自我纠错可能失效 | 不增加无条件多轮自我修订，不把模型等级当作校准概率，提升必须靠固定评分实际验证 |
| [FActScore, 2023](https://aclanthology.org/2023.emnlp-main.741/) | 逐原子事实检查支持性，而非整段二元判断 | 仅用于检查粒度和复核设计；保留项目原四指标，不替换评价器，也不查询外部个人资料推断 B |

冻结的 v4 方案：

1. 第一阶段复用 v2 coverage 的相同请求响应（部署时仍是一次生成），原候选最多 12 条。
2. 第二阶段一次独立归因与去语境化重构：查主体、反事实可否证、完整限定、语义去重、所有可见轮次遗漏。只接收候选的文本、属性名和证据，隐藏自评级和 confidence。允许删除、合并、忠实改写和从可见 A 恢复明确遗漏；不使用参考。
3. 最终最多 10 条，引用必须精确。空白修复改为唯一 token 序列匹配，保留词边界、大小写、标点和错码，禁止把 no one 与 none 合并。没有置信度阈值搜索或按对话 ID 的规则。
4. 两阶段预算为 512/3072 和 256/2048，替代 v3 三阶段，目标降低完整推断用量。
5. 一次完整 298 段追加；评价仍 prompts-v2.py、历史 validate_matches、score_item、four_metrics。主表 equivalent-only，另列宽松对照。旧十算法行冻结；EFCR v2 仅追加其自身报告行，不替换其另一次联合评审的历史六算法行。

预设比较：Precision、Recall、Grounded Recall 分别对比 v3 的 20.1141%、18.8776%、41.2214%；完整已知 token/298 对比 4024.389262。实际 mean_tokens 若有缺失 usage 继续 null，不能把下界改善说成严格第四指标已被证明改善。保留所有尝试及失败，不通过重采样追逐分数。

评价局限：588 条参考中仅 262 条是 E1/E2。严格证据驱动系统不应为了追求全参考 Recall 而猜测其余隐藏信息；只恢复 E1/E2 时对应全参考 Recall 上限为 262/588=44.56%，是这一特定证据目标下的上限，不是所有预测系统的绝对上限。连续在同一 298 段上迭代的效果需要未来独立数据确认。
