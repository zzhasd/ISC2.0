# Stage 2 execution and parsing deviations

The sampling, catalogue, provisional gold, attacker prompts, request payloads, and original protocol are frozen; their hashes are retained. No gold label or model assertion is changed based on results.

After 19 recorded responses, the run was stopped because full-dialogue multi-target responses were syntactically valid JSON but structurally malformed. Some explicitly emitted the second target as a string followed by its facts object/list; one flattened exact id/label/evidence key-value sequences into the array. `stage2_parse.py` mechanically recovers only explicit, unambiguous target/fact associations. It never fills in a missing target or a missing attribute. Raw responses remain unchanged. Strict-format failures, normalized calls and missing target outputs are reported. Available target results from an incomplete call are retained, rather than dropping that dialogue entirely. The full-vs-A paired analysis is restricted to actual available paired decisions and reports its denominator.

Stopping occurred during the seventh wave of three calls. Nineteen responses were recorded, and two additional requests may have reached the service without being recorded. Both are conservatively counted against the paid request cap. Their task ids are in `interruption_audit.json`. The original final two exact-repeat tasks are omitted so the conservative total stays at 100 attempts. Thus expected recorded output is 97 main/control calls plus one exact repeat, with up to two unlogged interrupted calls. Actual billed tokens for the interrupted requests cannot be recovered from local logs.

On resume, attempts are recorded before sending. The same frozen payloads are used; no new prompt or gold-label tuning occurs. The one remaining repeated view is a seed-selected sample, not an error-selected probe. One view is insufficient for a robustness claim. This deviation reduces the originally planned three-repeat check and must be visible in the final report.

A later request (`test_663` full control) failed with a TLS EOF transport error before a response body was recorded. The final exact repeat is also cancelled, and its budget is used for one explicitly recorded, same-payload transport retry. Therefore all three repeats are cancelled. This run makes no exact-payload reproducibility claim. Expected recorded output, if the retry succeeds, is 97 successful main/control calls plus one transport-failure record, with up to two additional unlogged interrupted attempts. Recorded tokens omit any unreturned server work.

Some later full responses have an unrecognizable remainder or invalid outer JSON. The analysis retains only already-complete target objects that can be decoded verbatim with a JSON decoder. Ambiguous remainder is missing output; no target identity, label, bracket, quote or escape is invented. Complete-object recovery and missing targets are counted separately. This may leave fewer full-control target views than A-only views; conditional full scores and matched-pair denominators must be reported as such.
