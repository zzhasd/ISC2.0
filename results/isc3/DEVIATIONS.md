# Execution and analysis notes

- The protocol and 2,902 initial unique requests were frozen before the first successful ISC3 call. No historical inputs, annotations or results were overwritten.
- The API credential supplied by the user is passed only through a child process's stdin. It is absent from source files, public request plans, raw response files, console output and manifests.
- A secondary sparse, exact-quote model audit of explicit assertions in generated B replies was proposed while initial calls were in progress, before inspecting reconstruction texts or comparing recovery outcomes. Automatic approval review rejected queueing that extra external API workflow, stating that this additional reconstruction-content egress to Alibaba had not been separately authorized. It was not retried or bypassed. `isc3_reconstruction_audit.py` is an unexecuted proposed audit, not evidence of completed calls. The replacement `isc3_local_reconstruction_audit.py` runs offline only: canonical sentence-initial first-person predicates in fictional structured replies are counted conservatively, and natural reconstructions are exported unscored for human review. Main E2 final-extraction unsupported-claim metrics remain distinct from this limited supplementary audit.
- Chinese counterparts are manually authored semantic counterparts of the mechanisms, not certified literal translations of every English surface form. Language and surface phrasing effects are partly confounded. English candidate propositions are retained.
- RECOVER-B here is a two-pass prompted prototype, not a trained speaker-grounded contrastive model. The graph baseline is a prompted graph analogue, not a reproduction of GraphProfiler. No published 1SC implementation is claimed; missing-reply reconstruction is 1SC-style.
- Structured support sets are author-coded sufficient sets for a particular reading, not proven necessary evidence or human-established information ceilings. In incomplete prefixes an alternative support set may exist; support-unavailable counts should be read as a conservative annotation proxy.
- Calibration uses a small clustered pilot. Bootstrap bounds do not guarantee population FDR and can degenerate with zero observed errors. A separate one-sided cluster-any-error bound is exported to make limited precision visible; it is a different risk estimand.
- E5 uses only qwen3.8-flash as explicitly requested. Cross-family independence, human gold/adjudication, a trained SGCI component and independently verified open-world recall remain outstanding.
- An interim offline dry run was used only to validate parsing/statistics/figure code while requests were pending. It exposed why plotting whatever responses happened to exist at each prefix can change the cohort. Final normalized curves therefore enforce the protocol's fixed-cohort intent: every integer prefix must be valid for both Direct and RECOVER-B, or the entire view is excluded from both main curves. Joint-only E3 comparisons likewise require every singleton to be present. Missing and invalid outputs remain exported separately.
- Natural random/enriched strata and exclusion of already-marked policy-sensitive attribute items are supplementary sensitivity analyses. Gold and selected thresholds are not changed. No hypothesis tests or population guarantees are inferred from unadjusted descriptive bootstrap intervals.
- Source-text inspection during execution identified pronoun/agreement artifacts inherited from correction templates and the literal Casey→me holder substitution (for example "me would" and "you, rather than ..., is"). Frozen prompts and primary results are preserved. `surface_quality_flags.csv` records source-only regex flags, and a secondary E5 sensitivity excludes an entire opposite-holder group if any compared English variant has a flagged form. This does not certify grammaticality or naturalness, does not retune thresholds/gold, and is not a corrected-data rerun.
- Reconstruction schema validation checks the number of hypotheses and validity of returned reply references, not exactly one reply at every A position. Some model generations stop normally while returning only a fragment. These actual pipeline outputs are preserved rather than filled in or selectively rerun; `E2_reconstruction_coverage.csv` and the report expose per-hypothesis reply-position coverage. The canonical-phrase audit is deliberately very sparse and is not an estimate of total reconstruction assertion risk.
- Because v1 single-hypothesis reconstruction had only 52.1% mean reply-position coverage on controlled test views, a completeness-controlled E2 v2 was frozen in `ISC3_RECONSTRUCTION_V2_PROTOCOL.md`. Both one- and three-hypothesis generation are rerun for all 184 views with explicit empty output skeletons, followed by the unchanged extraction prompt. V1 is preserved. This is a documented outcome-aware baseline repair, not a pre-v1 confirmatory registration or selective failure-only retry. No denied external assertion judge is included. The added generation/extraction workflow remains within the user-authorized E2 task and original 6,000-attempt/8M-token envelope.
